# 🌤️ Weather App  

A simple and modern weather application built with **HTML, CSS, and JavaScript**. It allows users to search for any city and get real-time weather updates, including temperature, weather conditions, and date & time.  

## 🚀 Features  
- 🌍 Search weather by city name  
- ⏱️ Displays current date and time  
- 🌡️ Real-time temperature and weather condition updates  
- 📱 Responsive design for all devices  
- 🔍 Search input with Enter key support  

 

## 🛠️ Tech Stack  
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6+)**  
- **OpenWeatherMap API**
